# **App Name**: 學習筆記通

## Core Features:

- 建立與編輯筆記: 用戶可以創建、編輯和刪除課業筆記，並支持富文本格式編輯。
- 筆記瀏覽介面: 提供清晰易讀的介面，方便用戶查看所有筆記內容。
- 筆記分類與標籤: 允許用戶對筆記進行分類和添加標籤，以便於管理和查找。
- 筆記搜尋功能: 提供全文檢索功能，幫助用戶快速找到特定筆記。
- 筆記安全儲存: 安全地儲存和讀取用戶的個人筆記數據，確保資料不丟失。

## Style Guidelines:

- Primary color: A sophisticated and professional blue (#336699) to convey clarity and focus, ideal for academic work.
- Background color: A very light, slightly cool-toned grey (#F0F2F4) to ensure maximum readability and reduce eye strain for extended study sessions.
- Accent color: A vibrant cyan (#26D9D9) to provide clear visual cues for interactive elements and highlights, offering a refreshing contrast.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, clean, and structured feel that complements academic content.
- Body text font: 'Inter' (sans-serif) selected for its exceptional readability, neutrality, and professional appearance, crucial for extensive note-taking.
- Utilize a set of minimalistic and crisp line icons to represent actions like creating, editing, categorizing, and searching notes, maintaining a clean aesthetic.
- Implement a clear, well-structured two-column layout with a navigation sidebar and main content area for optimal information organization and user experience.
- Incorporate subtle and swift transitions for actions such as opening and closing notes, filtering content, or switching views, ensuring a smooth and responsive interface without distraction.
